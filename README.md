## Cakupan

| Bab | Materi |
|---|---|
| 0 | Mengapa Struktur Aljabar? |
| 1 | Himpunan, Pemetaan, dan Operasi |
| 2–4 | Grup, Subgrup, Grup Siklik, dan Orde |
| 5–6 | Permutasi, Simetri, dan Grup Dihedral |
| 7–8 | Koset, Partisi, dan Teorema Lagrange |
| 9–11 | Homomorfisme, Normalitas, Kuosien, dan Isomorfisme |
| 12–13 | Aplikasi dan Sintesis Teori Grup |

Contoh, kotak intuisi, pertanyaan eksplorasi, latihan bertahap, dan jawaban
terpilih mendukung pembacaan mandiri. Jilid Ring dan Lapangan sedang
dikembangkan dan belum termasuk dalam publikasi ini.

## Status naskah

Bab 0–13 telah mendapat revisi awal. Contoh terpilih dihitung ulang;
rujukan silang, hasil kompilasi, dan tampilan halaman telah diperiksa.
Pemeriksaan ini belum merupakan audit matematis independen seluruh buku.
Bibliografi, indeks, solusi lengkap latihan, dan kegiatan digital masih
perlu dilengkapi. Versi ini dapat berubah selama penelaahan berlangsung.

ChatGPT digunakan sebagai alat bantu pengembangan dan penelaahan.
Pernyataan penggunaan AI dan batas pemeriksaan terdapat di bagian awal
buku. Keputusan akhir mengenai isi dan penerbitan berada pada penulis.
