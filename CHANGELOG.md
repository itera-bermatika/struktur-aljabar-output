# Riwayat Perubahan

## Web 0.3 — 22 Oktober 2026

- Empat aksioma grup dinyatakan eksplisit: ketertutupan, asosiativitas, identitas, invers.
- Penyelarasan definisi, contoh, kuis, subgrup, dan grup kuosien.
- Laboratorium operasi menampilkan pemeriksaan keempat aksioma.
- PDF publik diselaraskan dengan revisi buku empat aksioma.

## Web 0.2.1 — 22 Oktober 2026

- Penyelarasan rumus sebaris ke garis dasar teks, tanpa padding vertikal.
- Ukuran rumus mengikuti ukuran huruf setempat, termasuk pada ponsel.
- Gulir rumus ditempatkan pada pembungkus agar garis dasar SVG terjaga.

## Web 0.2 — 22 Oktober 2026

- MathJax 4.1.3 dengan STIX Two, disajikan bersama web tanpa CDN.
- Sumber LaTeX eksplisit pada bacaan, latihan, dan penjelasan jawaban.
- Typesetting hasil laboratorium, termasuk pecahan, koset, dan pemetaan.
- Perbaikan indeks, pangkat, himpunan, serta matriks dua dimensi.
- Antrian rendering untuk perubahan parameter dan pergantian bahasan.
- Pemeriksaan seluruh 14 bahasan di desktop dan ponsel.

## Web 0.1 — 22 Oktober 2026

- Bacaan web pendamping Bab 0–13: 14 bahasan dan 14 jeda konsep.
- Enam laboratorium operasi modular, koset, permutasi, simetri,
  homomorfisme, serta pewarnaan persegi.
- Pencarian bahasan, catatan refleksi, dan kemajuan baca lokal browser.
- PDF lengkap tetap tersedia; versi web merupakan adaptasi ringkas.

## 0.1 — 22 Oktober 2026

- Publikasi awal draf lengkap jilid Grup, Bab 0–13, sebanyak 379 halaman.
- Penyelarasan jalur baca, istilah citra, notasi, dan identitas jilid.
- Pengembangan contoh, eksplorasi, dan jawaban terpilih.
- Pemeriksaan contoh terpilih, rujukan silang, kompilasi, dan tampilan.
